# Tu Destino Taxi — Publicación gratis

1. Crea un repositorio público llamado `tu-destino-taxi` en GitHub.
2. Sube todos los archivos de esta carpeta al nivel principal del repositorio.
3. En Settings → Pages selecciona Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub generará una dirección como `https://TUUSUARIO.github.io/tu-destino-taxi/`.
5. Ábrela en Safari del iPhone → Compartir → Añadir a pantalla de inicio.

Esta versión es una PWA/prototipo. Para una operación real faltan backend, cuentas, GPS en tiempo real, notificaciones, base de datos y pagos.
